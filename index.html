How to play

Every box is a value in the circuit. Fill them all in using four rules.

  • V = I × R for each resistor, and for any group of them.
  • Series, one path: the current is the same everywhere. Voltages add up, and so do resistances.
  • Parallel, side-by-side branches: every branch gets the same voltage. Currents add up. R = 1 ÷ (1/R₁ + 1/R₂ …)
  • The battery's voltage is across the whole circuit, and its current is the total current.

Drag any value onto another box, or onto a calculator slot, to copy it there.

Calc picks an operation. Tap values in the circuit to drop them in, then put the result in the box you chose.

Meter measures one box for you. Normal puzzles give you 3 as hints. Meter puzzles start with too few clues: measure the fewest boxes you can. Par is the fewest possible.

Easy uses whole numbers, Medium one decimal place, and Hard two. Tap Check when you want to know how you're doing.
